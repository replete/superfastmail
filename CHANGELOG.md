# Changelog

Each release needs a `## x.y.z` section here, matching `version` in package.json: the release workflow publishes it as the release notes.

## 1.0.0

First release.

**Mail**
- Conversation list with Inbox, Unread, Pinned, VIPs and All tabs, and a folder picker
- Search within the tab you're on, matching partial words as you type
- Conversation reader: expand or collapse all, attachments, embedded images, remote images off until you ask, dark mode for HTML email
- Archive, delete, spam, read or unread, pin and move, one at a time or in bulk, all with undo
- Fastmail's keyboard shortcuts
- Compose, reply, reply all and forward, with identities, signatures, contact suggestions, formatting and attachments
- Drafts that survive the dropdown closing, with Save draft and Discard; an empty new message is let go
- Undo send and schedule send
- Vacation response

**Notifications**
- Desktop notifications for new mail (can be switched off) and a test notification
- 17 sounds with volume, or none
- Do Not Disturb
- Live updates by push, with polling as a fallback; unread count on the toolbar icon

**Calendar** (CalDAV)
- Agenda, week and month views, with each calendar as a chip to show or hide
- Create, edit, move and delete single events
- Event reminders as desktop notifications

**Files** (WebDAV)
- Browse, download and preview images
- Upload (button or drag and drop), new folder, rename, move and delete

**Also**
- Contacts and Masked Email
- Settings in the dropdown (notifications, appearance, vacation response, updates); Help with keyboard shortcuts and About
- Credentials encrypted under a lock of your choice: none, password, passkey or security key
- Light and dark themes, comfortable or compact lists, a pop-out window
- Firefox and Chrome builds
